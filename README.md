## Getting Started

Kalau baru mulai
1. Buat projek flutter dari VS code (tata caranya cari sendiri)
2. Sambungin VS code sama akun github (tata cara cari sendiri)
3. git clone repository ini. Nanti akan ada folder pocket-receipt di device. Folder yang ke"download" cuma branch main
4. Folder pocket-receipt bisa di-merger sama folder projek yang dibikin di poin 1
5. Mulai coding, simpan file di folder lib

## How to updating progress

1. git pull
2. cek branchnya di pojok kiri bawah vs code
3. save perubahan file (ctrl+s)
4. git commit -am "(deskripsi perubahan max. 3 kata)"
5. git push origin Nama_Branch
